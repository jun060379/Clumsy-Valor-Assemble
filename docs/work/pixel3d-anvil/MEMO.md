# pixel3d 모루

- 2026-11-07: "좋아 다음" → 모루 착수.
  → 적용: 옆에서 본 모루 윤곽(넓은 발, 잘록한 허리, 어깨, 네모난 뒤꿈치, 왼쪽 뿔)을 깊이 방향으로 밀어낸 쇠 덩어리 + 위 강철판, 나뭇결 홈이 있는 네모 받침목. K 0.12.
- 2026-11-07: "요건 살짝 텍스쳐감 끌어올리자"
  → 적용: 잡티 없이 모양으로만 — 받침목: 길이가 고르지 않은 나뭇결 홈, 위에서 내려오는 마른 균열, 옹이, 모서리 나무껍질. 모루: 면과 뿔 사이 한 단 낮은 받침, 각구멍·둥근구멍, 발 사이 아치. (앞날 밝은 테두리·윗면 나이테는 튀어서 뺌)
- 2026-11-07: "결 사이사이 빗 들어오는 연출 가능하나?"
  → 적용: 나뭇결을 실제 홈으로 파냄(앞면을 1.5 두께 판으로 만들고 홈에서 끊음). 해 쪽을 보는 홈 벽(외곽선=면)이 해 색으로 밝아짐 — 오전엔 홈의 왼벽, 오후엔 오른벽. 아침·저녁엔 앞면이 그늘이라 안 보임.
