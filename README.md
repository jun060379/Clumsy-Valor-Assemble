# Clumsy Valor [어설픈 용맹] -Assemble-

고도 4 (GDScript) 이식판. main 브랜치에 올라가면 자동으로 빌드된다.

- 웹: https://jun060379.github.io/Clumsy-Valor-Assemble/
- 윈도우: Actions → 최신 build → Artifacts의 ClumsyValor-windows

## 진행

- [x] 0단계: 프로젝트 뼈대, 자동 빌드
- [x] 1단계: 에스텔 기본 조작 (이동·정지·방향 전환, 점프·2단 점프, 대시·공중 대시, 지상 3타, 위/아래 공격, 공중 콤보, 내려찍기, 모아 찌르기, 방패)
- [x] 2단계-1: 몬스터 4종(고블린·독버섯·해골 광부·동굴 눈알)과 웨이브, 피격·방패·패링, 극한 회피, 효과음, 한글 글꼴, 체력 표시
- [x] 2단계-2: 아이다·루체(각자 공격·스킬·모으기), 교대, QTE 태그(수호·기습·구원), 교대 패링, 공중 태그
- [x] 3단계-1: 버섯 동굴 (방 지도 생성, 방 8종 지형, 웨이브·증원, 정예, 보스 감독관 해골, 쉼터·보물방, 문·표지판·빛, 미니맵)
- [ ] 3단계-2: 마을
- [ ] 3단계-3: 길드 본관
- [ ] 4단계: UI 연출
- [ ] 5단계: 길드 시스템

## 조작 (방향키형)

- 이동: 방향키 (같은 방향 두 번 = 대시)
- 점프 Z · 공격 X · 스킬 A (에스텔 방패 · 아이다 균열 · 루체 치유) · 대시 Shift · 교대 Ctrl 또는 C
- 공격 길게 누르기 = 모아 찌르기, 위+공격 = 올려베기, 아래+공격 = 앉아 베기, 공중에서 아래+공격 = 내려찍기
- 동굴: 훈련장 오른쪽 끝 동굴 입구에서 공격 키. 문 앞에서 공격 키로 다음 방
- 시험용 키(PC): F2 동굴 바로 입장, F3 방 정리, F4 다음 방
- 폰: 왼쪽 절반 아무 데나 끌면 이동 스틱, 오른쪽 버튼, 오른쪽 위 얼굴을 누르면 교대
