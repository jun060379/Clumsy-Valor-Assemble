## 조작 (방향키형 · 설정에서 WASD + 마우스형으로 바꾸거나 칸마다 키를 바꿀 수 있다)

- 이동: 방향키 (같은 방향 두 번 = 대시)
- 궁극기 D (기력이 가득 차고 30초 재사용 대기가 끝나면) · 마우스 좌클릭 = 공격, 우클릭 = 스킬(방향키형) / 대시(WASD형) · F 전체화면 · 오른쪽 위 ≡ = 메뉴 (패드 Start)
- 점프 Z · 공격 X · 스킬 A (에스텔 방패 · 아이다 균열 · 루체 치유) · 대시 Shift · 교대 Ctrl 또는 C
- 공격 길게 누르기 = 모아 찌르기, 위+공격 = 올려베기, 아래+공격 = 앉아 베기, 공중에서 아래+공격 = 내려찍기
- 마을에서 시작(저장이 있으면 마지막 자리에서). 훈련장 입구 → 훈련장, 출격 마차 또는 마을 양 끝으로 걸어 나가기 → 던전 선택(Enter 출격 · Esc 닫기 · ←→ 탭). 문 앞에서 공격 키
- 아래 광장 분수대 앞에서 공격 키(또는 위) = 파티 편성 (최대 3명, 조작 중인 동료는 뺄 수 없음)
- 저장: user://save.json 하나. 장면이 바뀔 때와 파티를 바꿀 때 자동 저장
- 본관: 마을 테라스의 본관 문 → 1층 로비. 계단 끝에서 위 방향키로 계단에 올라서고, 층계참의 아치 앞에서 공격 키로 위층. 접수대에서 공격 키 = 에일린과 대화
- 동굴: 문 앞에서 공격 키로 다음 방. 돌아오면 출격 마차 앞
- 대화: 공격·점프 키나 대화창 탭 = 글자 다 보이기 → 다음 줄
- 설정: ↑↓(패드 십자키·왼쪽 스틱)로 줄 고르기, ←→로 값 바꾸기, Enter(패드 A)로 키 칸 잡기
- 마을: 파티에 없는 동료 곁에서 공격 키 = 한마디, 대장간 앞 브랜 곁에서 공격 키 = 대화 (대장간 화면은 준비 중)
- 시험용 키(PC): F2 동굴 바로 입장(훈련장에서), F3 방 정리, F4 다음 방, F5 마을 순간이동, F6 시간 +3시간, F7 본관 바로 입장(어디서나), F8 본관 다음 층, F9 에일린을 지금 시간의 자리로, F10 날씨(맑음·비·눈), F11 루체 파티 탈퇴/복귀 (Shift+F11 아이다), F12 기력 가득, Shift+F4 보스방 바로
- 폰: 왼쪽 절반 아무 데나 끌면 이동 스틱, 오른쪽 버튼(스킬 버튼은 동료마다 가드·균열·힐 그림과 재사용 대기, 문·사람 앞에서는 공격 버튼이 입장·대화 등으로 바뀜), 버튼 위 ULT 태그를 누르면 궁극기, 오른쪽 위 얼굴을 누르면 교대

## 시험용 키 정리 (PC, 나중에 뺄 것)

- F2 동굴(훈련장에서) · F3 방 정리 · F4 다음 방 · Shift+F4 보스방 · F5 마을 순간이동 · F6 +3시간 · F7 본관 · F8 다음 층 · F9 에일린 위치 · F10 날씨 · F11 / Shift+F11 루체·아이다 파티 빼기
- F12 경험치 +100·의뢰 하나 완료 · Shift+F12 명성 +30 · Ctrl+F12 장 타이틀카드 · Alt+F12 등급 컷 미리보기
- Home 룬·장비·실링·피로도 지급 · End 룬 도감 · Page Down 보스방(Shift: 피로도 10) · Insert 기력 채우기

## 남은 차이

원본(estelle-prototype.html)과 비교해 아직 옮기지 못한 것과 그 까닭.

- 캐릭터 화면의 스킬·기억·기록 탭: 원본은 캐릭터마다 기억 노드 25개(가지 3개·혼합 노드·핵심 노드), 레벨 업과 돌파(기억석), 노드마다 전투 효과(피해·받는 피해·대시 충전·자동 패링·성소 등), 메모리얼 해방, 기록 탭(이명·소속·한마디·대사집), 스킬 시연까지 있는 큰 시스템이다. 전투 훅이 수십 개라 이번 점검 범위를 넘어서 "준비 중"으로 남겼다. 캐릭터 레벨 배율(LVCURVE)도 이 시스템에 묶여 있어 지금은 Lv 1 배율이다.
- 화면 효과의 빛 번짐(블룸): 원본은 WebGL로 화면을 흐리게 복사해 더한다. 고도 호환 렌더러에서는 흐린 화면 사본을 싸게 만들 수 없어(폰에서 느려짐) 뺐다. 충격파·색수차·비네트·피격 번쩍임·극한 회피 색보정은 있다.
- 극한 회피 중 소리: 원본은 모든 소리에 저역 필터를 걸고 느리게 한다. 지금은 효과음 높이만 낮춘다(환경음 루프와 대화 목소리는 그대로).
- 본관의 쥐와 화분 소리, 원본 본관의 부딪히면 흔들리는 소품: 본관 소품에 충돌 판정이 없어 옮기지 않았다.
- 캐릭터 도트화는 셰이더로 흉내 낸 것이다: 원본은 캐릭터를 월드 픽셀 캔버스에 한 번 그린 뒤 읽어 들여 고치므로 움직일 때 격자가 화면에 붙어 있지만, 여기서는 격자가 스프라이트에 붙어 있다. 빛 방향 기준도 칸 높이로 어림한다.
- 궁극기 영상은 원본 영상(Theora)을 24fps · 640×360 JPEG 묶음으로 바꿔 쓴다(tools/make_ult_seq.py). 원본보다 약간 흐리다.
- 폰에서 줄인 것: 마을 줄 전구 빛을 7개에서 3개(대신 넓게)로. 웹 + 터치 기기에서만 적용된다.
- 원본에서도 "준비 중"인 것(마을 창고·헛간·목욕집·숯가마 문, 아이다·루체의 길 던전, 고유 룬의 동료 개인 의뢰)은 그대로 둔다.
- 대화 선택지 아이콘(말풍선·나가기)은 그리지 않는다.
