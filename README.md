## 조작 (방향키형 · 설정에서 WASD + 마우스형으로 바꾸거나 칸마다 키를 바꿀 수 있다)

- 이동: 방향키 (같은 방향 두 번 = 대시)
- 궁극기 D (아직 효과 없음) · 마우스 좌클릭 = 공격, 우클릭 = 스킬(방향키형) / 대시(WASD형) · F 전체화면 · 오른쪽 위 ≡ = 메뉴 (패드 Start)
- 점프 Z · 공격 X · 스킬 A (에스텔 방패 · 아이다 균열 · 루체 치유) · 대시 Shift · 교대 Ctrl 또는 C
- 공격 길게 누르기 = 모아 찌르기, 위+공격 = 올려베기, 아래+공격 = 앉아 베기, 공중에서 아래+공격 = 내려찍기
- 마을에서 시작. 훈련장 입구 → 훈련장, 출격 마차 → 버섯 동굴. 문 앞에서 공격 키
- 본관: 마을 테라스의 본관 문 → 1층 로비. 계단 끝에서 위 방향키로 계단에 올라서고, 층계참의 아치 앞에서 공격 키로 위층. 접수대에서 공격 키 = 에일린과 대화
- 동굴: 문 앞에서 공격 키로 다음 방. 돌아오면 출격 마차 앞
- 마을: 파티에 없는 동료 곁에서 공격 키 = 한마디, 대장간 앞 브랜 곁에서 공격 키 = 대화 (대장간 화면은 준비 중)
- 시험용 키(PC): F2 동굴 바로 입장(훈련장에서), F3 방 정리, F4 다음 방, F5 마을 순간이동, F6 시간 +3시간, F7 본관 바로 입장(어디서나), F8 본관 다음 층, F9 에일린을 지금 시간의 자리로, F10 날씨(맑음·비·눈), F11 루체 파티 탈퇴/복귀 (Shift+F11 아이다)
- 폰: 왼쪽 절반 아무 데나 끌면 이동 스틱, 오른쪽 버튼, 오른쪽 위 얼굴을 누르면 교대
