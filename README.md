# Clumsy Valor [어설픈 용맹] -Assemble-

길드 《어설픈 용맹》의 세 모험가 에스텔·아이다·루체를 번갈아 조작하는 2D 액션 게임. 길드 마을과 본관에서 지내며 의뢰를 받고, 출격 마차를 타고 버섯 동굴로 나가 몬스터와 보스를 쓰러뜨린다. 동료 교대와 QTE 태그, 방패·패링·극한 회피, 궁극기, 속성 상성, 룬과 장비(대장간), 캐릭터 레벨과 기억 노드, 길드 수첩의 의뢰와 명성이 있다. 진행은 자동 저장된다.

고도 4 (GDScript) 이식판. main 브랜치에 올라가면 자동으로 빌드된다.

- 웹: https://jun060379.github.io/Clumsy-Valor-Assemble/
- 윈도우: Actions → 최신 build → Artifacts의 ClumsyValor-windows

## 조작 (방향키형 · 설정에서 WASD + 마우스형으로 바꾸거나 칸마다 키를 바꿀 수 있다)

### 키보드·마우스

- 이동: 방향키 (같은 방향 두 번 = 대시)
- 궁극기 D (기력이 가득 차고 30초 재사용 대기가 끝나면) · 마우스 좌클릭 = 공격, 우클릭 = 스킬(방향키형) / 대시(WASD형) · F 전체화면 · 오른쪽 위 ≡ = 메뉴 (패드 Start)
- 점프 Z · 공격 X · 스킬 A (에스텔 방패 · 아이다 균열 · 루체 치유) · 대시 왼쪽 Shift · 교대 왼쪽·오른쪽 Ctrl
- 공격 길게 누르기 = 모아 찌르기, 위+공격 = 올려베기, 아래+공격 = 앉아 베기, 공중에서 아래+공격 = 내려찍기
- 마을에서 시작(저장이 있으면 마지막 자리에서). 훈련장 입구 → 훈련장, 출격 마차 또는 마을 양 끝으로 걸어 나가기 → 던전 선택(Enter 출격 · Esc 닫기 · ←→ 탭). 문 앞에서 공격 키
- 파티 화면(메뉴의 파티, 오른쪽 위 파티 단추, 아래 광장 분수대 앞에서 공격 키, 본관 리빙 룸): 동료마다 세로 그림 칸, 누르거나 ←→ = 동료 고르기, ↓·Enter = 아래 단추줄(빼기·넣기 / 리더로 / 정보), ↑ = 칸으로 돌아가기, Esc = 닫기 (최대 3명, 조작 중인 동료는 뺄 수 없음, 정보 = 그 동료의 캐릭터 화면)
- 저장: user://save.json 하나. 장면이 바뀔 때와 파티를 바꿀 때 자동 저장
- 본관: 마을 테라스의 본관 문 → 1층 로비. 계단 끝에서 위 방향키로 계단에 올라서고, 층계참의 아치 앞에서 공격 키로 위층. 접수대에서 공격 키 = 에일린과 대화
- 동굴: 문 앞에서 공격 키로 다음 방. 돌아오면 출격 마차 앞
- 대화: 공격·점프 키나 대화창 탭 = 글자 다 보이기 → 다음 줄
- 설정: ↑↓(패드 십자키·왼쪽 스틱)로 줄 고르기, ←→로 값 바꾸기, Enter(패드 A)로 키 칸 잡기
- 캐릭터 화면: ←→ 또는 Q/E(패드 LB/RB)로 탭. 스킬 탭 ↑↓ 기술 고르기. 기억 탭은 방향키로 노드를 고르고(맨 윗줄에서 위 = 레벨 업·돌파 단추, 맨 아랫줄에서 아래 = 초기화, 이때 ←→는 탭), Enter(패드 A) = 활성화·해제·레벨 업. 기록 탭 ↑↓ 대사 고르기, Enter = 듣기(Lv12면 맨 위 ◎ 감상), 서 있는 그림을 누르면 한마디(빠르게 세 번 = 연타), 감상 중 Esc = 돌아가기. 의상 탭 ↑↓ 의상 고르기, Enter = 입기
- 마을: 파티에 없는 동료 곁에서 공격 키 = 한마디, 대장간 앞 브랜 곁에서 공격 키 = 대화
- 옷장(본관 2층 복도 끝 문, 명성 2등급에 시설 복구): ←→ 의상 고르기, Q/E 동료, ↑↓ 거울 속 동작, Enter = 입기 / 구매(두 번), 거울을 누르면 다음 동작

### 패드

- A 점프 · X 공격 · Y·LT 스킬 · B 대시 · RT 궁극기 · LB·RB 교대 · Start 메뉴 · Back 설정 (왼쪽 스틱·십자키 이동)

### 터치 (폰·태블릿)

- 왼쪽 절반 아무 데나 끌면 이동 스틱, 오른쪽 버튼(스킬 버튼은 동료마다 가드·균열·힐 그림과 재사용 대기, 문·사람 앞에서는 공격 버튼이 입장·대화 등으로 바뀜), 버튼 위 ULT 태그를 누르면 궁극기, 오른쪽 위 얼굴을 누르면 교대

## 개발자용 (플레이어는 볼 필요 없음)

### 디버그 게이트

시험용 키, 브라우저 점검용 `window.*` 훅, URL 스위치, 빌드 표시는 모두 `scripts/dev.gd`의 `DEV.on` 하나에 묶여 있다. `DEV.on`은 디버그 빌드(에디터 실행, `-s` 테스트, `--export-debug`)에서만 참이고, `--export-release`로 뽑은 빌드에서는 늘 거짓이라 아래 것이 하나도 동작하지 않는다(실행 인자·URL·저장·설정으로 켤 수 없다).

- 시험용 키(PC, 디버그 빌드만)
  - F2 동굴(훈련장에서) · F3 방 정리 · F4 다음 방 · Shift+F4 보스방 · F5 마을 순간이동 · F6 +3시간 · F7 본관 · F8 다음 층 · F9 에일린 위치 · F10 날씨 · F11 / Shift+F11 루체·아이다 파티 빼기 · Insert 기력 채우기
  - F12 경험치 +100·의뢰 하나 완료 · Shift+F12 명성 +30 · Ctrl+F12 장 타이틀카드 · Alt+F12 등급 컷 미리보기
  - Home 룬·장비·실링·기억석·피로도 지급 · End 룬 도감 · Page Down 보스방(Shift: 피로도 10) · Page Up 의상 전부 지급
  - 길드 수첩이 열려 있어도 F1~F12는 지나간다
- 웹 훅(디버그 웹 빌드만): `cvaTest`(`skins` = 의상 전부, `page wardrobe` = 옷장), `cvFame` / `cvFameState`, `cvaP1`, `cvaTrain` / `__train`, `cvaTS` / `cvaT`, `cvaBook`, `cvaX`(아레나에서 GDScript 식 실행), `__ts` / `__gs`
- URL 스위치(디버그 웹 빌드만): `?tsctl`, `?slowtx`, `?uiclock`
- 빌드 표시: 왼쪽 아래 `STEP 4 · UI · <날짜> · <해시>`, 타이틀 오른쪽 아래 `<날짜> · <해시>`

### 빌드와 테스트

- 테스트: `godot --headless --import` 뒤 `godot --headless -s tests/test_*.gd` (디버그 빌드라 게이트가 열려 있다). 테스트 실행은 `user://save_test.json`을 쓰고 타이틀을 건너뛴다.
- 내보내기: `export_presets.cfg`의 Web·Windows 둘 다 `tests/`, `tools/`, `docs/`, `build/`를 뺀다. `build/`에는 `.gdignore`가 있어 고도가 내보낸 파일을 가져오지 않는다.

### 의상(코스튬)

의상 목록은 `scripts/skin_data.gd`, 소유·착용·해금과 그림 찾기는 `scripts/skins.gd`(모든 화면이 캐릭터 그림을 여기서 받는다). 그림 규격과 넣는 법은 `docs/skin_assets.md`, 포즈 레퍼런스는 `docs/skin_ref/`. 에스텔의 기본 의상은 초심(부분 완성: 대기·출발·멈춤·돌아서기·점프·달려 점프·달리기·걷기), 원래 그림은 "미숙한 결의"(이야기 보상). 초심에 없는 줄은 원래 그림이 그 줄에서만 나온다. 이야기 시스템이 생기면 `arena.skins.grant(id, "story")` 또는 `arena.skins.story(키)`로 지급한다.

### 남은 차이

원본(estelle-prototype.html)과 비교해 아직 옮기지 못한 것과 그 까닭.

- 극한 회피 중 소리: 원본처럼 모든 소리(효과음·환경음·목소리)가 "Slow" 버스를 지나 저역 필터(520 Hz)·작은 소리·낮은 재생 속도로 바뀌었다가 돌아온다(scripts/slow_bus.gd). 원본처럼 이미 울리던 효과음은 원래 속도 그대로이고 루프만 느려진다. 높이는 재생 속도(pitch_scale)로 바꾼다(피치 시프트 효과 대신, 원본의 playbackRate와 같은 방식).
- 본관의 쥐와 화분 소리, 원본 본관의 부딪히면 흔들리는 소품: 본관 소품에 충돌 판정이 없어 옮기지 않았다.
- 캐릭터 도트화(shaders/char_pix.gdshader): 원본 charPix를 픽셀 단위로 맞췄다. 월드 픽셀 격자(정수 좌표)에서 크롬 캔버스의 리샘플(미리 곱한 8비트 텍셀, 1/16 단위 쌍선형, 경계 판정까지)을 흉내 내고, 몸마다 슬롯(player.gd pix_slot)에 정확한 좌표 변환·위아래 밝기 기준(스프라이트 실제 위·아래 줄, scripts/char_bounds.gd)·가까운 빛 셋의 테두리광을 싣는다. 마을·훈련장은 해·달 빛도 테두리광에 들어간다. 대기 숨쉬기(가슴 늘이기), 달리기 흔들림, 무적 깜빡임(그리지 않음), 피격 흰 번쩍임, 잔상 색도 원본대로. 남은 차이: 고립 렌더 비교에서 스프라이트 픽셀의 0.2~1%(GPU 부동소수 경계). 조명(그늘·광원 가산)은 조명 작업 쪽.
- 픽셀 이펙트(scripts/pfx.gd)·잔상·빛 번짐: 원본 PFXL·AFX·TELLFX·PARRYFX·POST를 옮겼다. 빛 번짐은 월드 캔버스를 1/4 크기 SubViewport로 다시 그려 만든다(HUD는 번지지 않음). 아이다 베기의 장면 미끄러짐(DC_SLIP)은 원본에서도 꺼져 있어 옮기지 않았다.
- 궁극기 영상은 원본 영상(Theora)을 24fps · 640×360 JPEG 묶음으로 바꿔 쓴다(tools/make_ult_seq.py). 원본보다 약간 흐리다.
- 마을·본관 빛(원본 drawLighting 그대로): 건물·나무 그림자가 해 방향으로 기울어 늘어나고, 구름 그림자가 땅·건물·소품·주인공 위로만 흘러가며(아래 광장 제외), 테라스 아래 광장은 짙은 그늘이다. 가로등은 빛 덩이·아래로 퍼지는 원뿔·바닥 웅덩이, 모닥불은 위로 기우는 불빛, 줄 전구, 서 있는 문 앞의 따뜻한 빛. 빛은 더하기로 그려 캐릭터를 알베도째 밝히지 않는다(캐릭터는 주변광과 테두리 빛만). 18:40부터 본관 창문에 불이 들어오고 가끔 누가 창을 지나가며, 앞에 선 주인공이 창을 가린다. 밤하늘 별 90개와 달, 새벽 06:20 무렵 안개, 먼 아지랑이 세로 그라데이션, 하늘에도 주변광이 곱해진다.
- 폰에서 줄인 것: 그늘 마스크를 화면의 1/3 크기로, 그림자 번짐 단계를 9에서 5로. 웹 + 터치 기기에서만 적용된다.
- 훈련장도 마을과 같은 빛(울타리·나무 셋의 해 그림자, 구름 그림자, 가로등 원뿔·웅덩이, 밤하늘·안개). 본관 벽난로·화덕·샹들리에는 복구 전이면 불·빛이 없고 샹들리에는 어둡게 걸려 있다. 동굴도 원본 drawLighting·drawTerrain대로: 밤빛 남색 주변광을 곱하고 횃불·랜턴·빛나는 버섯·수정·문·주인공 둘레의 빛을 웅덩이로 더한다. 바위 덩어리(뒷벽·옆벽·바닥과 솟은 바위·발판)는 원본처럼 아트 해상도로 구워(cave_ter.gd, 템플릿마다 한 번, 백그라운드 스레드) 각 빛을 향한 8방향 테두리가 그 빛 색으로 밝고 반대쪽은 어두워진다(천장은 원본대로 테두리 없음). 열린 문은 바닥에 빛을 흘리고, 캐릭터와 몬스터도 방의 빛으로 테두리를 받는다. 원본이 그리지 않는 바위·이끼·수레 같은 장식은 뺐다.
- 원본에서도 "준비 중"인 것(마을 창고·헛간·목욕집·숯가마 문, 아이다·루체의 길 던전, 고유 룬의 동료 개인 의뢰)은 그대로 둔다.
- 대화 선택지 아이콘(말풍선·나가기)은 그리지 않는다.
- 훈련장 SCORE · BEST 줄: 원본은 점수를 세지만 그 줄(#hud)이 게임 캔버스 밑에 깔려 보이지 않는다. 여기서도 점수(arena.score / best)만 센다.
